# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

报警班测要在检查员设定的分钟内确认，超时未确认的测点进顶栏的“催办榜”，同时写一条催办大事记。确认时要填处置简述，确认后测点离榜，大事记保留并变为确认完毕。分钟门槛单独存表，改完立刻生效。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3191 |
| 接口 | http://localhost:8191 |
| PostgreSQL | localhost:54391 |

## 启动

```bash
cd projects/12-mine-methane-shift
docker compose up --build
```

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
3. viewer 登录后没有上报表单。
4. 点顶栏“催办榜”，把确认时限改成 0 分钟保存，回风巷立刻进榜，大事记多一条“催办中”。
5. 在榜上给回风巷填处置简述并确认，该点离开催办榜，大事记还在且状态变为“确认完毕”。
6. viewer 登录能看催办榜和大事记，但没有确认按钮，也不能改分钟数。
