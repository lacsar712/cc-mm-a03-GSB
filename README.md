# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

报警必须在检查员设定的分钟内完成确认；超时未确认的测点进入**催办榜**并写一条催办大事记，确认时需填写处置简述。榜上按测点归并。确认后该点离榜，大事记保留并标记为"确认完毕"。

## 催办榜

- 顶栏入口叫**催办榜**，含：分钟门槛设置、催办榜（按测点归并）、催办大事记。
- 分钟门槛单独存表（`urgent_settings`），检查员修改后立即生效（保存即按新门槛扫描）。
- 分钟设为 `0` 时，报警即刻上榜。
- gasman（检查员）：可上报、可确认、可改分钟数；viewer（旁观）：能看榜和大事记，不能确认，也不能改分钟数。
- 服务端每 5 秒兜底扫描一次，上报、改设置时也会立即扫描；榜单变更通过 websocket 实时推送。

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
3. viewer 登录后没有上报表单。
4. 打开顶栏**催办榜**，把确认时限改成 `0` 并保存：回风巷种子测点立刻进榜，大事记同时出现一条"待确认"记录。
5. 在榜上为回风巷填写处置简述并确认：该点立即离开催办榜；大事记仍保留该条，状态变为"确认完毕"，并记录确认人和确认时间。
6. 换 viewer 登录：能看到催办榜和大事记，但分钟数输入框只读、没有保存按钮、榜上没有确认入口；直接调接口也会被拒绝（403）。
